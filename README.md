# Mini Store Tests : 

This repository contains the unit and integration tests for the **Mini Store** project, implemented using **Vitest** and **React Testing Library**. 

The goal of these tests is to verify shopping cart behavior(remove, add) , product filtering, state management, and user interactions.

## Tech Stack
* React & TypeScript
* Vitest
* React Testing Library

## How to Run the Tests

To run the test suite, run the following commands in your terminal:


# Install dependencies
npm install

# Run tests
npm test
